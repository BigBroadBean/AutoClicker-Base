# AutoClicker

一个轻量级 Windows 连点器，采用**侧边栏导航 + 新拟态（Neumorphism）UI**，基于 C++20 和 GDI 开发，支持深/浅两套主题。

- **横向窗口**：640×480 经典 4:3 宽高比，两列卡片布局，信息密度高
- **默认亮色主题**：柔和浅色新拟态，可随时切换深色
- **高性能连点**：1ms 系统定时器 + 亚毫秒级精确休眠（忙等精调），点击间隔误差 <0.1ms，CPS 精准控制；空闲 CPU 占用 ≈ 0%
- **现代字体**：自动选用系统中最美观的中文字体（Noto Sans SC > HarmonyOS Sans SC > MiSans > 思源黑体 > 微软雅黑），英文数字同样受益
- **柔和视觉**：按钮悬停呈现多层圆角光晕，全界面元素带柔和投影阴影（Region 精确几何，圆角完美贴合）
- **兼容输入法钩子**：窗口标题通过 ANSI API 创建，点击发送动态调用 PostMessage 绕过输入法 IAT 钩子

## 功能

- **侧边栏导航**：连点 / 多倍 / 滚轮 / 高级 四个页面，各功能独立配置、互不干扰
- **鼠标左/右键连点**：可分别调节 CPS（每秒点击次数），实时显示延迟
- **CPS 快捷预设**：一键切换 6 / 10 / 15 / 20 次每秒
- **多倍点击模式**：可配置倍数（1-5 倍）与间隔延迟（1-200ms），支持 2x/3x/4x/5x 与 10/25/50/100ms 预设，+/- 键微调倍数
- **滚轮点击**：滚轮滚动转换为左/右键点击，可切换按键方向
- **随机 CPS**：在设定范围内随机波动，模拟真人操作
- **仅能攻击时连点**（直接连点的附属功能）：自动向 Minecraft Java 进程注入 MCCombatStatusJni.dll，通过 UDP 35785 端口实时接收“能否攻击准星目标”（0/1，5ms 刷新），开启后**仅左键**连点会在可攻击时进行，右键不受影响；未开启时照常连点。支持 **1.8.9 / 1.12.2 / 1.20.1（含对应 Forge 版本）**
- **仅手持放置物时右键连点**（直接连点的附属功能，配合上面同一 DLL）：UDP 报文同时携带第 2 个字节“手持物品是否为放置物”（0/1，与可攻击状态同步 5ms 刷新），开启后**仅右键**连点会在左手持方块类放置物（ItemBlock/BlockItem）时进行；未开启时右键照常连点。开启本功能即自动注入 DLL（与左键功能共用同一注入通道）
- **CPS 上限**：防止连点过快（可手动输入）
- **定时自动停止**：连点 N 秒后自动关闭（可手动输入秒数）
- **HWID 使用调查上报**：启动时向写死的服务器上报本机唯一硬件标识（基于 MachineGuid，格式 `HW-xxxx`），地址为 `servercfg.h` 中的域名+端口常量（当前 `http://counter.bigbroadbean.top:3000/report?hwid=...`，无配置文件）；后台线程发送、5 秒超时，服务器不可用不影响正常使用；结果记录在 `%APPDATA%\AutoClicker\report.log`
- **启动时版本检查**：启动时请求服务器最新版本号（`GET /version/latest`，服务器地址与上报共用 `servercfg.h` 写死的域名+端口）并与本地版本对比；有新版本则 MessageBox 弹窗提示（显示最新版本号 + 更新内容，内容来自 `GET /content/latest`）；已是最新或服务器不可用时静默不打扰，日志在 `%APPDATA%\AutoClicker\update.log`

- **实时 CPS 显示**：状态栏右下角实时显示当前点击速率（1 秒滑动窗口），连点/停止实时变化
- **自定义快捷键**：点击按钮后按下任意键绑定（Esc 清除），有引导提示
- **保持模式**：开启后无需长按快捷键即可自动连点
- **窗口置顶**：一键固定窗口在最前
- **新拟态 UI**：浮雕/内凹质感，暗色与浅色双主题，Toast 通知同步换肤
- **响应式窗口**：窗口可缩放，卡片自适应高度，小屏幕自动适配
- **键盘导航**：方向键左右/上下切换页面
- **极致轻量**：除 Windows SDK 外无任何外部依赖

## 环境要求

- Windows 10 或更高版本
- Visual Studio 2022+（v143+ 工具集），安装 C++ 桌面开发工作负载

## 构建

1. 用 Visual Studio 打开 `AutoClicker.sln`
2. 选择配置：
   - **`Release | x64`** —— 网络版：HWID 使用上报 + 启动时版本检查（定义 `AUTOCLICKER_NET` 宏）
   - **`Release-Base | x64`** —— 基础版：不编译任何网络模块（不上报、不检查更新）
3. 生成 → 生成解决方案（Ctrl+Shift+B）

或通过命令行构建：

```powershell
msbuild AutoClicker.sln /p:Configuration=Release /p:Platform=x64          # Net 网络版
msbuild AutoClicker.sln /p:Configuration=Release-Base /p:Platform=x64      # Base 基础版
```

构建需要仓库根目录存在 `MCCombatStatusJni.dll`（PreBuildEvent 会自动复制到项目目录并作为 RCDATA 资源嵌入 exe）。

## 使用说明

- **侧边栏**：点击左侧图标切换页面（连点 / 多倍 / 滚轮 / 高级），也可用方向键切换
- **连点页**：左右键开关 + CPS 滑块 + 预设按钮 + 连点快捷键 + 保持模式 + 仅能攻击时连点 / 仅手持放置物时右键连点（各含状态芯片与快捷键）
- **多倍页**：倍率/延迟滑块 + 预设 + 多倍快捷键
- **滚轮页**：滚轮点击开关 + 左/右键选择 + 两个快捷键
- **高级页**：CPS 上限、随机 CPS、定时自动停止
- **快捷键**：点击快捷键按钮绑定按键（按 Esc 清除），用于启停对应功能
- **仅能攻击时连点**：连点页第三行开关；开启后**仅左键**在准星对准可攻击目标时才连点（右键照常），状态栏第 4 个指示灯实时显示 0/1（第 5 个为放置物状态），连点页有 可攻击/不可攻击/未连接 状态芯片，可绑快捷键；DLL 缺失/游戏未运行时按”不可攻击”处理（fail-safe）
- **仅手持放置物时右键连点**：连点页第四行开关；开启后**仅右键**在左手持放置物（方块）时才连点（左键照常），状态栏第 5 个指示灯实时显示 0/1，连点页有 手持放置物/非放置物/未连接 状态芯片，可绑快捷键；同一 UDP 通道（2 字节报文），与「仅能攻击时连点」相互独立、可同时开启
- **自动注入**：开启「仅能攻击时连点」或「仅手持放置物时右键连点」后后台循环扫描 javaw/java 进程（1 秒周期），自动把 MCCombatStatusJni.dll 注入所有未注入的我的世界 Java 版进程（窗口类 GLFW30/LWJGL 识别，仅 x64，不重复注入，进程重启后重新注入）；**两个功能都关闭时不注入任何进程**。注意：网易中国版（游戏盒子）有反作弊保护，注入会被检测并导致游戏关闭，无法使用本功能
- **单文件分发**：MCCombatStatusJni.dll 已内嵌进 exe，启动时自动释放到 `%TEMP%\AutoClicker\`，无需手动放置；若 exe 同目录存在 MCCombatStatusJni.dll 则优先使用（便于更新 DLL）
- **计数**：状态栏右下角显示本次会话点击总数，点击可重置
