# AutoClicker

一个轻量级 Windows 连点器，采用**侧边栏导航 + 玻璃态（Glassmorphism）UI**，基于 C++20 和 GDI 开发，支持深/浅两套主题。

- **玻璃态窗口**：整窗分层透明渲染（UpdateLayeredWindow + 32bpp 预乘 Alpha 三层缓存），**无边框设计**——自绘标题栏（最小化/最大化/关闭窗控 + 提示音 + 置顶 + 主题 + 方案芯片），四角圆角桌面透出，可拖动/边缘缩放/双击标题最大化/贴靠；窗口基底半透明，卡片/侧栏/状态栏为玻璃面板 + 发丝描边 + 顶部高光渐变 + 柔和投影；深色为「深空玻璃」蓝调，浅色为「雾白玻璃」
- **横向窗口**：640×480 经典 4:3 宽高比，两列卡片布局，信息密度高；窗口位置/尺寸记忆
- **高性能连点**：1ms 系统定时器 + 亚毫秒级精确休眠（忙等精调），点击间隔误差 <0.1ms，CPS 精准控制；空闲 CPU 占用 ≈ 0%
- **丝滑动效**：页面切换 160ms 滑入+淡入（内容层预渲染缓存，动画帧仅 2 次 AlphaBlend + 呈现，稳定 60fps）；Toast 滑入动画；4 色强调色即时切换
- **现代字体**：自动选用系统中最美观的中文字体（Noto Sans SC > HarmonyOS Sans SC > MiSans > 思源黑体 > 微软雅黑），灰度抗锯齿适配透明背景
- **兼容输入法钩子**：窗口标题通过 ANSI API 创建，点击发送动态调用 PostMessage 绕过输入法 IAT 钩子

## 功能

- **侧边栏导航**：连点 / 多倍 / 滚轮 / 面板 / 高级 五个页面，各功能独立配置、互不干扰；页面切换带 160ms 滑入动画
- **配置方案**：标题栏 4 个方案芯片一键切换整套设置（CPS/快捷键/门控/主题/拟人化…），面板页可重命名，可绑定切换热键；旧版配置文件自动迁移
- **鼠标左/右键连点**：可分别调节 CPS（每秒点击次数），实时显示延迟
- **CPS 快捷预设**：一键切换 6 / 10 / 15 / 20 次每秒
- **多倍点击模式**：可配置倍数（1-5 倍）与间隔延迟（1-200ms），支持 2x/3x/4x/5x 与 10/25/50/100ms 预设，+/- 键微调倍数
- **滚轮点击**：滚轮滚动转换为左/右键点击，可切换按键方向
- **随机 CPS**：在设定范围内随机波动，模拟真人操作
- **拟人化节奏**：均匀 / 双击连招 / 呼吸波动 / 疲劳递减 四种点击节奏 + 强度调节（1-5），可与随机 CPS 叠加
- **实时 CPS 面板**：12 秒 CPS 曲线 + 实时速率 + 累计点击 + 会话时长；状态栏右下角同步显示迷你曲线与数值
- **游戏状态面板**：连接状态 / 游戏内 / 准星目标实体 / 命中类型 实时显示（共享内存 HUD 快照，无需开启门控也有数据——前提是游戏里已注入 DLL）
- **强调色**：蓝 / 紫 / 绿 / 橙 四色可选，全局即时生效
- **仅能攻击时连点**（直接连点的附属功能）：自动向 Minecraft Java 进程注入 MCCombatStatusJni.dll，优先通过共享内存（`Local\MCCombatStatus_<PID>`）实时读取“能否攻击准星目标”（0/1，5ms 刷新），旧版 DLL 由 UDP 35785 端口兜底；开启后**仅左键**连点会在可攻击时进行，右键不受影响；未开启时照常连点。支持 **1.8.8 ~ 1.21.11 几乎全版本（原版 / Forge / Fabric / NeoForge）**
- **仅手持放置物时右键连点**（直接连点的附属功能，配合上面同一 DLL）：状态通道同时携带第 2 个状态“手持物品是否为放置物”（0/1，与可攻击状态同步 5ms 刷新），开启后**仅右键**连点会在左手持方块类放置物（ItemBlock/BlockItem）时进行；未开启时右键照常连点。开启本功能即自动注入 DLL（与左键功能共用同一注入通道）
- **CPS 上限**：防止连点过快（可手动输入）
- **定时自动停止**：连点 N 秒后自动关闭（可手动输入秒数）
- **HWID 使用调查上报**：启动时向写死的服务器上报本机唯一硬件标识（基于 MachineGuid，格式 `HW-xxxx`），地址为 `servercfg.h` 中的域名+端口常量（当前 `http://counter.bigbroadbean.top:3000/report?hwid=...`，无配置文件）；后台线程发送、5 秒超时，服务器不可用不影响正常使用；结果记录在 `%APPDATA%\AutoClicker\report.log`
- **启动时版本检查**：启动时请求服务器最新版本号（`GET /version/latest`，服务器地址与上报共用 `servercfg.h` 写死的域名+端口）并与本地版本对比；有新版本则 MessageBox 弹窗提示（显示最新版本号 + 更新内容，内容来自 `GET /content/latest`）；已是最新或服务器不可用时静默不打扰，日志在 `%APPDATA%\AutoClicker\update.log`
- **自定义快捷键**：点击按钮后按下任意键绑定（Esc 清除），有引导提示
- **保持模式**：开启后无需长按快捷键即可自动连点
- **窗口置顶**：一键固定窗口在最前；窗口位置/尺寸关闭时记忆、下次启动恢复
- **提示音开关**：标题栏喇叭按钮一键静音/恢复所有系统提示音（开关/连点/门控），开关自身保留确认音；随方案保存
- **玻璃态 UI**：半透明玻璃面板/发丝描边/柔和投影，深色「深空玻璃」与浅色「雾白玻璃」双主题，4 色强调色，Toast 通知滑入动画
- **响应式窗口**：窗口可缩放，卡片自适应高度，小屏幕自动适配
- **键盘导航**：方向键左右/上下切换页面
- **极致轻量**：除 Windows SDK 外无任何外部依赖

## 环境要求

- Windows 10 或更高版本
- Visual Studio 2022+（v143+ 工具集），安装 C++ 桌面开发工作负载

## 构建

1. 用 Visual Studio 打开 `AutoClicker.sln`
2. 选择配置：
   - **`Release | x64`** —— 网络版：HWID 使用上报 + 启动时版本检查（定义 `AUTOCLICKER_NET` 宏）
   - **`Release-Base | x64`** —— 基础版：不编译任何网络模块（不上报、不检查更新）
3. 生成 → 生成解决方案（Ctrl+Shift+B）

或通过命令行构建：

```powershell
msbuild AutoClicker.sln /p:Configuration=Release /p:Platform=x64          # Net 网络版
msbuild AutoClicker.sln /p:Configuration=Release-Base /p:Platform=x64      # Base 基础版
```

构建需要仓库根目录存在 `MCCombatStatusJni.dll`（PreBuildEvent 会自动复制到项目目录并作为 RCDATA 资源嵌入 exe）。

## 使用说明

- **侧边栏**：点击左侧图标切换页面（连点 / 多倍 / 滚轮 / 面板 / 高级），也可用方向键切换
- **标题栏方案芯片**：点击即切换整套配置方案（自动保存当前方案、读入目标方案）；悬停看方案名，面板页可重命名；可在高级页绑定「方案切换」热键循环切换
- **连点页**：左右键开关 + CPS 滑块 + 预设按钮 + 连点快捷键 + 保持模式 + 仅能攻击时连点 / 仅手持放置物时右键连点（各含状态芯片与快捷键）
- **多倍页**：倍率/延迟滑块 + 预设 + 多倍快捷键
- **滚轮页**：滚轮点击开关 + 左/右键选择 + 两个快捷键
- **面板页**：实时 CPS 曲线与累计点击/会话时长；游戏连接/游戏内/目标实体/命中类型；方案重命名与强调色
- **高级页**：CPS 上限、随机 CPS、定时自动停止、拟人化节奏（均匀/双击/呼吸/疲劳 + 强度）
- **快捷键**：点击快捷键按钮绑定按键（按 Esc 清除），用于启停对应功能
- **仅能攻击时连点**：连点页第三行开关；开启后**仅左键**在准星对准可攻击目标时才连点（右键照常），状态栏第 3 个指示灯实时显示 0/1（第 4 个为放置物状态），连点页有 可攻击/不可攻击/未连接 状态芯片，可绑快捷键；DLL 缺失/游戏未运行时按”不可攻击”处理（fail-safe）
- **仅手持放置物时右键连点**：连点页第四行开关；开启后**仅右键**在左手持放置物（方块）时才连点（左键照常），状态栏第 4 个指示灯实时显示 0/1，连点页有 手持放置物/非放置物/未连接 状态芯片，可绑快捷键；与「仅能攻击时连点」共用同一状态通道（共享内存为主、UDP 2 字节报文兜底），相互独立、可同时开启
- **自动注入**：开启「仅能攻击时连点」或「仅手持放置物时右键连点」后后台扫描 javaw/java 进程（1 秒周期，注入失败按 1s→30s 指数退避重试），自动把 MCCombatStatusJni.dll 注入所有未注入的我的世界 Java 版进程（窗口类 GLFW30/LWJGL 识别，仅 x64，不重复注入，进程重启后重新注入）；**两个功能都关闭时不注入任何进程**。注意：网易中国版（游戏盒子）有反作弊保护，注入会被检测并导致游戏关闭，无法使用本功能
- **单文件分发**：MCCombatStatusJni.dll 已内嵌进 exe，启动时自动释放到 `%TEMP%\AutoClicker\`，无需手动放置；若 exe 同目录存在 MCCombatStatusJni.dll 则优先使用（便于更新 DLL）
- **计数**：状态栏与面板页实时显示会话点击速率与总数（面板页含 12 秒 CPS 曲线）
