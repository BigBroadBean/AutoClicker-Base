# 界面风格精修方案(新拟态 · 布局不动)

## 目标
在现有新拟态绘制体系上做视觉打磨,提升立体感、层次感与交互反馈。只改绘制/配色,不动 `Layout()` 的矩形、不动状态与数据逻辑。

## 改动明细

### 1. `types.h` — 色板精修
- **加深浅色主题暗影**:`CLR_SHADOW_DK_LIGHT` RGB(197,202,212) → RGB(184,190,203)(与背景对比从 ~31 提到 ~44,凸起更明显)
- **加深深色主题暗影 / 提亮高光**:`CLR_SHADOW_DK_DARK` RGB(27,28,34) → RGB(23,24,31);`CLR_SHADOW_LT_DARK` RGB(60,62,72) → RGB(64,66,78)
- **新增描边色**:加 `CLR_OUTLINE_DARK` RGB(33,34,41) / `CLR_OUTLINE_LIGHT` RGB(206,211,221) 常量 + `OUTLINE()` 访问器(卡片与背景同色时靠描边清晰分隔表面)

### 2. `main.cpp` — 表面描边与层次
- 给三大表面各加一条 1px 细描边(绘制在 `NeuRaised` 之后,与现有「滚轮分段选择器」的描边写法一致):
  - 侧边栏 `L.sidebar`(line 734)
  - 内容卡片循环 `L.card[i]`(line 771)
  - 状态栏 `L.status`(line 1215)
  - 悬浮 tooltip `L.t`(line 1319,可选,保持统一)

### 3. `main.cpp` — 悬停与交互反馈(`NeuButton`,lines 575-589)
- 悬停光晕峰值 alpha 0.22 → 0.18(减少「泛光」,更利落)
- 悬停表面提亮 0.45 → 0.50
- 悬停时新增 1px 强调色细环 `DrawRoundRect(..., LerpC(ACCENT(), BG(), 0.35f), 1)`(跟手反馈更清晰)
- 按下态 `NeuInset` 深度 2 → 3(更有按压手感)

### 4. `main.cpp` — 标题与状态栏
- **标题文字**:去掉双层投影(现 offset +2 和 +1 两层),简化为单层柔和阴影(offset +1,`LerpC(SHADOW_DARK(), BG(), 0.3)`),更干净
- **实时 CPS 芯片**(lines 1284-1293):`GetRealtimeCps() > 0` 时文字用 `ACCENT()`/绿色高亮,有活动时更醒目;静止保持默认色

### 5. `overlay.cpp` — Toast 一致性(仅靠色板自动生效)
- Toast 阴影/高光走 `SHADOW_DARK()/SHADOW_LIGHT()`,types.h 改后自动加深,无需改代码

## 不改动
- `Layout()` 所有矩形、命中热区、DPI/字体选择
- 任何状态机、连点/注入/网络逻辑、配置读写
- 版本号
